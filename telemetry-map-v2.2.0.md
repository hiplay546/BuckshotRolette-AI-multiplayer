# Карта телеметрии: Buckshot Roulette v2.2.0

Источник: восстановленный проект из копии Steam-сборки build `16736575`. Все пути ниже относятся к `work\extracted`.

## Подтверждённый мультиплеер

В проекте есть отдельная папка `multiplayer` и сетевые скрипты. Игра использует сокеты `0`–`3`: `MP_RoundManager.GetSocketFromDirection` содержит явное сопоставление направлений для всех четырёх сокетов. Это подтверждает четырёхместный режим в коде установленной версии.

Сеть проходит через `MP_PacketManager` и Steam P2P. Мод не должен подменять пакеты или результат игры; наблюдать следует обработчики уже применённых пакетов и завершённых игровых действий.

## Точки записи первой версии

| Событие журнала | Подтверждённая точка в исходниках | Данные, доступные в точке |
| --- | --- | --- |
| начало раунда | `MP_RoundManager.PacketSort`, alias `first round routine` | номер раунда, первый сокет, словарь раунда |
| зарядка | `MP_RoundManager.MainRoutine_LoadShotgun` и `PacketSort`, alias `load shotgun routine` | первый сокет, публичный словарь последовательности |
| смена активного игрока | `MP_RoundManager.PassTurn(to_socket)` | предыдущий и новый сокет, имя игрока, таймер хода |
| взятие и размещение предмета | `MP_ItemManager.GrabItem`, `PlaceItem` | сокет, ID предмета, локальная ячейка |
| применение предмета | `MP_ItemInteraction.InteractWithItem_*` и `ChangeGameStateWithItem` | владелец, ID, параметры применённого действия |
| выстрел | `MP_ShotgunInteraction.Shoot`, `ReceivePacket_Shoot`, `ShootingOutcome` | стрелок, выбранная цель, тип снаряда, результат |
| здоровье и выбывание | `MP_UserInstanceProperties` и `MP_DeathManager.UserDeath_*` | сокет, здоровье, вход в режим наблюдателя |
| смена хода после выстрела | `MP_RoundManager.UserEndTurn_Packet` и `MainRoutine_UserEndTurn` | стрелок, следующий сокет, пуст ли дробовик |
| завершение матча | `MP_RoundManager.GameConclusion` | итоговая статистика матча |

## Ограничения видимости

Последовательность патронов нельзя помещать в общий журнал, доступный моделям. Для зрительского лога допускается только подтверждённый итог выстрела. Личный результат лупы и другие приватные эффекты должны записываться отдельной записью с полем `visibility: private` и адресатом-владельцем.

## Технический способ подключения

Первый вариант подключения — наложить на рабочую копию изменённые GDScript-файлы через `GDRE Tools --pck-patch`, оставляя оригинальную Steam-установку неизменной. До первой записи изменяются только рабочая копия и файлы проекта.

Перед патчем необходимо проверить версию Godot, которой собран исходный EXE, и собрать минимальную замену скрипта с тем же форматом. Из-за этого первый исполняемый мод создаётся после проверки версии движка.
